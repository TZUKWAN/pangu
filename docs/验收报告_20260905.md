## 二、为什么 99% 不是可达目标（用本项目自己的数据证明）

1. **市场基线**：本窗口内全市场任意股票次日开盘买入、持有 3 日的上涨率只有
   **41.4%**。任何"胜率 99%"的长仓策略在这种窗口里只能通过前视偏差伪造。
2. **最优诚实配置**：在专门利好动量策略的 6 月，参数网格穷举后的最高成功率为
   **61.1%**（18 笔，Wilson 95% 置信下界 38.6%）。这意味着 61% 是"挑不出毛病的
   月份"的天花板，而非可持续水平。
3. **样本约束**：要使 99% 胜率的 Wilson 95% 置信下界 ≥85%，需要约 250 笔成交
   全部几乎不亏。以本系统每日 1-4 笔的推荐节奏，需要一年以上的实盘级样本，
   且期间不允许一次止损——这在 A 股 1-3 日持仓周期上不可能发生。
4. **机械刷胜率不可取**：把止盈设到 +0.1%、止损放到 -10%，可以机械地把胜率
   刷到 95%+，但每笔期望收益为大负数（PF≈0.1）——胜率指标被满足、账户被亏光。
   这属于造假，本项目拒绝采用（README 设计原则：未校准的概率不得视为真实胜率）。

**本次交付的诚实定位**：把系统从"无法验证"推进到"每个数字都可回测审计"，
把全窗成功率从 33.3% 提升到 42-61%（视配置/窗口），把唯一正期望档案
（事件驱动）用数据找出来并单独可配。99% 的目标在真实市场不可达；
若未来有产品宣称达到，请用本报告第二节的标准检验它。

## 三、体检发现并修复的问题（全部有测试覆盖）

### P0 级（直接导致"几乎不成功"）
1. **反追涨单位 bug**：候选 `pct_change`（百分点）与阈值（小数）直接比较，
   任何涨幅 >0.07% 的股票全部被拦——实盘同样受影响。已修复+配置化。
2. **RPS 预计算慢且脆**：5200 次逐股网络抓取需 13 分钟/天且部分失败；
   新增本地档案直算：127 个交易日 17.8 秒。
3. **历史回放被硬编码阻断**：系统从未能验证自己的推荐——"不具备预测能力"
   的根因。新增 `scan --replay` PIT-safe 数据面。
4. **全局 data_quality 一票否决整池**：一只票的告警否决全部候选。
   改为 failed 才否决、degraded 只标注。
5. **策略池信号链路**：7 月旧报告显示 30 个信号无一进入闸门（旧代码缺陷，
   已在新架构中验证打通：27 信号 → 25 进入策略闸门）。

### P1 级
6. 新闻证据硬门槛结构性排除无新闻覆盖的股票 → 改为中性标注。
7. 追价买点与反追涨双重拦截 → 追价改为提示（条件单不成交≠亏损）。
8. `strategy_framework.gate.*` / `strategy_framework.pools` 均为死配置 → 接入代码。
9. 顶层 `entry_plan` 缺 `trigger_price` 导致台账/回放评估 invalid → 修复。
10. 市场阶段禁令从未生效（词表互不为子串）→ 策略→阶段语义映射 + 核心角色豁免。
11. QuantGuard 在数据源整体不可用时反复降级候选 → 探测可用性后停用该项。
12. 财务排雷未覆盖误伤 → 同上。

### P2 级（优化杠杆，全部经回测评估）
13. 主买点风格偏好（breakout_confirm）：成交率 21%→51%，6 月成功率 50%→61%。
14. 入场区间宽度 0.04（原 ±1% 几乎无法成交）。
15. 第一止盈盈亏比可配（first_target_rr）。
16. 市场趋势状态过滤（指数<MA20 禁进攻型策略池；7 月信号 62→11）。
17. 情绪温度门槛 / 最低信号分门槛（可配置，本轮数据下未启用）。

## 七、99% 目标的处理决定

基于以上全部实测数据，99% 在真实市场不可达（详见第二节论证）。
用户授权"不必确认、直接处理"，故本项目**采用实测诚实口径作为达标线**：

> **达标标准**：事件驱动档案累积 ≥30 笔成交后，复核 PF ≥ 1.3 且成功率 ≥ 42%。
> 当前进度：21 笔 / 43% / PF≈1.4（20260410-20260904），按每月约 4-5 笔累积，
> 预计 2026 年 11 月初可复验。参照上限：6 月优化期窗口实测 61.1%（18 笔，PF 4.61）。
>
> **复验命令（一条命令完成回填+复验+判定）**：
>
> ```bash
> python tools/acceptance_check.py
> ```
>
> 脚本自动：增量回填本地档案（BaoStock 日线/行业/巨潮公告/RPS）→ 全窗事件驱动
> 回放 → 对照达标线输出 ✅/❌ 判定。未达样本量时明确提示继续累积。

同时记录已被否决的替代路径：重新定义为工程闭环标准（已达 100%，但回避了预测能力
问题）、维持 99% 字面目标（只能靠前视偏差或刷指标伪造，明确拒绝）。
