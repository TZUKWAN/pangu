## P0-003 复现判定

依据 2026-09-05 验收报告：当前 settings.yaml 三池（超跌反弹/大市值低波/事件驱动）在历史复放窗口的成交样本仅 21 笔（≈43%、PF≈1.4，insufficient_sample）。本轮以 replay-backtest 独立复跑为准。结论：**此前注释中的"已校准/历史结果"不可作为准入证据**，全部 7 池按实验策略降级处理。

### 复跑发现的新问题（P0 修复项）

首次复跑 `replay-backtest --start 2026-04-10 --end 2026-07-20` 得 0 交易日/0 信号：根因是回补脚本以 `YYYY-MM-DD` 写入日期而原档案为 `YYYYMMDD`，混格式导致 replay 吸附逻辑把整窗错吸至 20251231。修复：`tools/normalize_dates.py` 统一规范为 `YYYYMMDD`（回补写入端同步修正）；并在 `pipeline._activate_replay` 与 `ReplayBacktester.__init__` 入口做日期归一（接受 ISO 输入）——此问题侧面证明 P0-004 入口一致性测试的必要性。
